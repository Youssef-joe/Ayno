🏗️ ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Event Published
      ↓
  ProcessorClient (wraps with circuit breaker)
      ↓
  GRPCClient (intelligent routing)
      ├─ TRY: gRPC on :9090 (binary, HTTP/2) [FAST]
      │   └─ Retry 3 times with backoff
      │   └─ If all fail → continue
      └─ FALLBACK: HTTP on :8080 (JSON) [COMPATIBLE]
          └─ If fails → circuit opens
          └─ After 30s → recovery attempt

  ├─ USE_GRPC=true                      (Enable gRPC)
  ├─ CIRCUIT_BREAKER_THRESHOLD=5        (Failures before open)
  └─ CIRCUIT_BREAKER_TIMEOUT=30000      (ms before recovery)
